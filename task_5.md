Вот описание атрибутов cookie на русском языке:

## Описание атрибутов cookie

**1. Name (Имя)**  
Имя cookie. Уникально идентифицирует cookie и используется для получения его значения при выполнении HTTP-запросов или операций на стороне клиента.

**2. Value (Значение)**  
Фактические данные, хранящиеся в cookie. Это значение передаётся между клиентом и сервером при каждом соответствующем запросе.

**3. Domain (Домен)**  
Указывает домен, для которого cookie действителен. Ограничивает доступ к cookie только указанным доменом и его поддоменами, предотвращая нежелательное использование на других сайтах.

**4. Path (Путь)**  
Определяет путь URL внутри домена, для которого cookie применяется. Cookie отправляется только для запросов, путь которых совпадает с указанным или является его подпутём.

**5. Expires / Max-Age (Срок действия)**  
Определяет время жизни cookie:

- **Expires (Истекает)**: Устанавливает абсолютную дату и время окончания срока действия (в формате GMT). Cookie удаляется после наступления этого времени.  
- **Max-Age (Максимальный возраст)**: Задаёт время жизни в секундах с момента установки cookie. По истечении этого срока cookie удаляется.  

Если ни один из параметров не указан, cookie является сессионным и удаляется при закрытии браузера.

**6. Size (Размер)**  
Размер cookie в байтах, показывающий объём памяти, который он занимает в хранилище браузера.

**7. HttpOnly**  
Если включён, cookie недоступен для JavaScript (например, через `document.cookie`), что снижает риск атак межсайтового скриптинга (XSS).

**8. Secure (Безопасный)**  
Если установлен, cookie передаётся только по защищённым HTTPS-соединениям, предотвращая перехват через незашифрованные HTTP-каналы.

**9. SameSite (Один и тот же сайт)**  
Контролирует отправку cookie в кросс-сайтовых запросах:

- **Strict (Строгий)**: Cookie отправляется только в контексте первого уровня (без кросс-сайтовых запросов).  
- **Lax (Умеренный)**: Cookie отправляется при переходе по ссылке на сайт (GET-запросы), но не при POST-запросах или встроенных ресурсах.  
- **None (Нет)**: Cookie отправляется во всех запросах, но требует установки атрибута **Secure**.

**10. Partition Key Site (Ключ разделения сайта)**  
Указывает, что cookie изолирован (разделён) по домену верхнего уровня. Такой cookie доступен только в контексте сайта, который его установил, что повышает конфиденциальность и предотвращает кросс-сайтовое отслеживание.

**11. Cross Site (Кросс-сайт)**  
Указывает, используется ли cookie в кросс-сайтовых контекстах. Если флаг установлен, это означает, что cookie может отправляться с запросами, инициированными с других сайтов, в соответствии с политиками SameSite и Secure.

**12. Priority (Приоритет)**  
Определяет приоритет обработки cookie браузером:

- **High (Высокий)**: Наивысший приоритет; обрабатывается первым.  
- **Medium (Средний)**: Стандартный приоритет.  
- **Low (Низкий)**: Пониженный приоритет; может быть отложен при высокой нагрузке.
