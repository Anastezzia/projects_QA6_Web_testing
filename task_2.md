# Chrome DevTools

Chrome DevTools (инструменты разработчика Google Chrome) — это набор встроенных в браузер инструментов для разработки, отладки и оптимизации веб-сайтов и веб-приложений. Они предоставляют широкие возможности для анализа производительности, диагностики ошибок, тестирования адаптивности и отладки кода.

## Назначение Chrome DevTools

- **Отладка JavaScript**  
  Позволяет выполнять пошаговое исполнение кода, устанавливать точки останова (breakpoints), просматривать значения переменных и объектов, анализировать стек вызовов и выявлять узкие места в производительности.

- **Анализ HTML/CSS/Layout**  
  Обеспечивает визуальный инспектор структуры страницы, возможность изменения стилей в реальном времени, проверку адаптивности через эмуляцию различных разрешений экрана, а также измерение позиционирования и размеров элементов.

- **Профилирование производительности**  
  Предоставляет инструменты для мониторинга использования памяти, загрузки процессора, времени рендеринга и общей производительности приложения.

- **Инспекция сетевых запросов**  
  Отображает все HTTP-запросы, выполненные браузером, включая заголовки, тела запросов и ответов, статус-коды, время загрузки и типы ресурсов.

- **Работа с консолью**  
  Позволяет выполнять произвольные JavaScript-команды, выводить отладочную информацию, получать доступ к DOM-элементам и использовать API браузера.

- **Эмуляция устройств**  
  Имитирует различные устройства, разрешения и условия сети, что упрощает тестирование адаптивного дизайна без использования физических устройств.

- **Просмотр локальных хранилищ и куки**  
  Даёт доступ к управлению данными, хранящимися на стороне клиента: cookies, localStorage, sessionStorage, IndexedDB, а также их атрибутами (secure, httpOnly, SameSite и др.).

- **Проверка доступности (Accessibility)**  
  Анализирует соответствие страницы стандартам WCAG и помогает выявить проблемы, затрудняющие использование сайта людьми с ограниченными возможностями.

## Методы вызова Chrome DevTools

1. **Горячие клавиши**  
   - Windows / Linux: `Ctrl + Shift + I` или `F12`  
   - macOS: `Cmd + Option + I`  
   - Быстрый выбор элемента: `Ctrl + Shift + C` (Windows/Linux) или `Cmd + Shift + C` (macOS)

2. **Контекстное меню**  
   - Клик правой кнопкой мыши на элементе → «Просмотреть код» («Inspect»)

3. **Меню браузера**  
   - Три точки в правом верхнем углу → «Дополнительные инструменты» → «Инструменты разработчика»

4. **Специальные страницы**  
   - `chrome://inspect/#devices` — для удалённой отладки подключённых устройств

## Основные вкладки Chrome DevTools и их применение в тестировании

### Elements
Позволяет просматривать и редактировать HTML и CSS в реальном времени. Используется для:
- Проверки структуры DOM
- Анализа и временного изменения стилей
- Определения корректных селекторов для автотестов
- Изучения позиционирования и размеров элементов через панель Layout

### Console
Среда для выполнения JavaScript-команд и отображения ошибок. Применяется для:
- Выявления JavaScript-ошибок и предупреждений
- Выполнения произвольного кода для манипуляции состоянием страницы
- Быстрой проверки поведения UI-компонентов

### Sources
Предоставляет доступ к исходному коду страницы и позволяет отлаживать JavaScript. Используется для:
- Установки точек останова
- Пошагового выполнения кода
- Анализа значений переменных в процессе выполнения
- Изучения логики работы скриптов

### Network
Отображает все сетевые запросы, сделанные страницей. Применяется для:
- Проверки корректности AJAX-запросов
- Анализа времени загрузки ресурсов
- Диагностики проблем с кэшированием
- Фильтрации и детального изучения отдельных запросов (заголовки, тело, статус)

### Performance
Позволяет записывать и анализировать производительность страницы. Используется для:
- Замера времени загрузки и взаимодействия
- Оценки использования CPU и GPU
- Выявления узких мест в рендеринге и выполнении JavaScript

### Memory
Инструмент для анализа потребления памяти. Применяется для:
- Обнаружения утечек памяти
- Оценки объёма используемых ресурсов
- Оптимизации работы приложения под слабые устройства

### Application
Даёт доступ к данным, хранящимся на стороне клиента. Используется для:
- Просмотра и редактирования cookies, localStorage, sessionStorage
- Работы с IndexedDB и Service Workers
- Тестирования сценариев, зависящих от сохранённого состояния

### Security
Отображает информацию о безопасности соединения. Применяется для:
- Проверки корректности SSL/TLS-сертификатов
- Выявления проблем со смешанным контентом (HTTP-ресурсы на HTTPS-странице)
- Анализа настроек безопасности cookies и заголовков

### Lighthouse
Автоматизированный инструмент аудита качества веб-страниц. Оценивает:
- Производительность загрузки и взаимодействия
- Соответствие стандартам доступности
- SEO-оптимизацию
- Соблюдение лучших практик
- Поддержку Progressive Web App (PWA)

Результаты представлены в виде отчёта с конкретными рекомендациями по улучшению.

### Recorder
Экспериментальный инструмент для записи и воспроизведения пользовательских сценариев. Позволяет:
- Записывать последовательность действий (клики, ввод текста, навигация)
- Экспортировать сценарии в формате для автоматизированного тестирования
- Воспроизводить сценарии для регрессионного тестирования
- Документировать воспроизведение дефектов
