### Задание 1. Клиент-серверная архитектура

1. Изучить трёхзвенную и многозвенную клиент-серверную архитектуру. Выписать основные компоненты многозвенной клиент-серверной архитектуры.
2. Написать назначение каждого из выписанных компонентов многозвенной архитектуры.
3. Изучить вопрос отказоустойчивости систем на основе «горячего» и «холодного» резерва. Написать определения, основные характеристики (готовность, синхронизация данных, время переключения, стоимость), плюсы и минусы для каждого вида.

### Задание 2. Chrome DevTools

1. Изучить подробнее назначение инструмента и методы его вызова.
2. Описать назначение каждой вкладки инструмента с точки зрения полезности тестировщику.

### Задание 3. Движки браузеров

1. Перейди на сайт «Школы 21»: <https://21-school.ru/>.
2. Протестировать сайт на отображение интерфейса в разных браузерах (Chrome, Firefox, Edge).
3. Сравнить результаты и выписать отличия в отображении элементов.

### Задание 4. Протоколы HTTP и HTTPS 

1. Изучи схему работы HTTPS-протокола и запиши каждый шаг данной схемы.
2. Перечисли основные группы кодов состояния HTTP и объясни их значение (1xx, 2xx, 3xx, 4xx, 5xx).

### Задание 5. Cookies

1. Перейти на любой сайт, который использует Cookies.
1. Открытьд Chrome DevTools и во вкладке «Application» найди сведения о Cookies. Посмотри и запиши, какие данные сайт записал о тебе, и обрати внимание на флаги: Secure, HttpOnly, SameSite.

### Задание 6. Тестирование UI веб-сайта

1. Открыть локально веб-сайт ([скачать файлы можно по ссылке](https://disk.360.yandex.ru/d/6xkKNnkKHp8MFA))
2. Перейти на страницу макета веб-сайта ([ссылка](https://www.figma.com/design/eTKqLIoG72PDLMuLUM4g7n/%D0%A1%D0%B1%D0%B5%D1%8021?node-id=0-1&t=JYeS1wlrz0uQePNr-1));
3. Сравнить макет с реализованным сайтом (макет считается эталоном);
4. Все найденные отличия завести в виде багрепортов.
